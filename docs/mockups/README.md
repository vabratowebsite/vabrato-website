# Mockups

Design reference for the Vabrato website, member portal, agent console and app. Match these layouts when building (see CLAUDE.md, Workflow).

**MLS-safe copies.** The repo is public, so these versions use fictional addresses, prices and listing numbers, and grey "LISTING PHOTO (FROM MLS FEED)" placeholders where real listing photos appear on the live site. Team photos and site banner images are Vabrato's own. Names, client data and stats are samples.
