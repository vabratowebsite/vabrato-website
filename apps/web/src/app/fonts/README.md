# Brand fonts (self-hosted)

The Latin variable fonts served by Google Fonts, downloaded 2026-11-13, so
builds don't fetch fonts over the network. Loaded by `../fonts.ts` with
`next/font/local`.

| File | Font | Weights | License |
|---|---|---|---|
| `bodoni-moda-latin.woff2` | Bodoni Moda | 400–900 | SIL Open Font License 1.1 (`OFL-bodonimoda.txt`) |
| `libre-baskerville-latin.woff2` | Libre Baskerville | 400–700 | SIL Open Font License 1.1 (`OFL-librebaskerville.txt`) |
| `libre-baskerville-italic-latin.woff2` | Libre Baskerville Italic | 400–700 | SIL Open Font License 1.1 (`OFL-librebaskerville.txt`) |
| `roboto-latin.woff2` | Roboto | 100–900 | SIL Open Font License 1.1 (`OFL-roboto.txt`) |

The files are unmodified. Keep each license file with its font.
